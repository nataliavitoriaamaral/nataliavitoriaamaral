##  Projetos em Destaque

* 🔗 **[Análise de Churn em E-commerce](https://github.com/nataliavitoriaamaral/ecommerce-revenue-analytics):** Desenvolvimento de um *dashboard* analítico focado na redução de taxas de cancelamento. Utilização de Python, Pandas e Streamlit para estruturar a visualização de dados e gerar *insights* estratégicos de negócios.
* 🔗 **[Banco de Dados Relacional - Streaming](https://github.com/nataliavitoriaamaral/sql_plataforma_streaming):** Modelagem e implementação de um banco de dados em SQL para uma plataforma de entretenimento. Estruturação abrangendo gestão de assinaturas, controle de pagamentos, catálogos especializados (filmes/séries) e histórico de visualização do usuário. 
* 🔗 **[Sistema de Recomendação Turística Inclusiva](https://github.com/nataliavitoriaamaral/sistema_recomedacao_turistica_neurodivergentes_mips):** Aplicação focada em acessibilidade para pessoas neurodivergentes (TEA). Atuei diretamente no back-end utilizando Assembly MIPS (MARS Simulator) para desenvolver algoritmos de recomendação, cálculo de *score* ponderado, ordenação (Bubble Sort) e otimização de memória por meio de vetores paralelos. A aplicação integra-se a um front-end web via Node.js.
